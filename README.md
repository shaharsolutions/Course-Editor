# ממשק עריכת לומדות (LMS Course Editor)

ממשק זה מאפשר לערוך לומדות הקיימות בתיקיית `LMS files`.
הוא תומך בהוספת קריינות (audio) לכל שקף ובשליטה מרחוק על זמן השהיית כפתור ה"המשך".

## תכונות מרכזיות:
- **ניהול שקפים**: שינוי כותרת, תוכן ותמונת רקע.
- **הוספת קריינות**: העלאת קבצי MP3/WAV לכל שקף.
- **שליטה בהשהיה**: 
  - אפשרות לחכות לסיום הקריינות לפני שניתן יהיה להמשיך.
  - הגדרת זמן השהייה מינימלי בשניות.
- **ממשק מודרני**: עיצוב פרימיום כהה המותאם למיתוג של שחר פתרונות דיגיטליים.

## הוראות הפעלה:
1. פתח את הטרמינל בתיקיית `LMS files/Course Editor`.
2. הרץ את הפקודות הבאות:
   ```bash
   npm install
   npm start
   ```
3. פתח את הדפדפן בכתובת [http://localhost:3030](http://localhost:3030).

## מעבר לפורמט החדש (JSON):
העורך יוצר קובץ `data.json` בתיקיית הלומדה.
כדי שהלומדה תשתמש בנתונים אלו, יש להחליף את הקובץ `scripts/main.js` בקיים בלומדה בקובץ `template-main.js` המצורף כאן (מומלץ לשמור גיבוי של `main.js` הישן).
